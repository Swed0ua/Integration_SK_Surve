# SmartKasa ↔  Integration

## Опис проєкту

Цей проєкт є масштабованим та структурованим інтеграційним рішенням для автоматичного обміну даними між системами. Основна мета — забезпечити надійну синхронізацію замовлень, чеків та іншої важливої інформації між двома платформами для автоматизації бізнес-процесів у сфері торгівлі та громадського харчування.

Проєкт підтримує логування подій, зберігання даних у базі даних (SQLite, файл syncbridge.db), а також роботу з конфіденційними налаштуваннями через файл .env. Архітектура дозволяє легко масштабувати та розширювати функціонал під індивідуальні потреби.

---

## Вимоги

- Python 3.8 або новіше
- pip (менеджер пакетів Python)
- Доступ до SmartKasa та Syrve API (ключі, токени)

---

## Інсталяція та налаштування

1. **Склонуйте репозиторій або скопіюйте файли проєкту у робочу директорію.**

2. **Встановіть залежності:**

   ```
   pip install -r requirements.txt
   ```

3. **Створіть файл .env у корені проєкту.**

   Заповніть його власними даними за зразком із .env.example (API-ключі, паролі, конфіденційні константи).

4. **Переконайтесь, що файл бази даних syncbridge.db знаходиться у корені проєкту.**

   Якщо файл відсутній, він буде створений автоматично при першому запуску, або зверніться до розробника для отримання шаблону.

---

## Запуск

Для запуску основного скрипта використовуйте команду:

```
python main.py
```

Скрипт можна запускати одноразово або налаштувати його періодичне виконання (наприклад, через планувальник завдань у Windows чи cron на Linux) як локально, так і на сервері.

## Структура проєкту

- `main.py` — основний скрипт запуску інтеграції
- `core/` — базова логіка, модулі для роботи з даними
- `services/` — сервіси для взаємодії з API, базою даних, логуванням
- `syncbridge.db` — файл бази даних SQLite
- `receipts.json` — приклад/джерело даних для синхронізації
- `.env` — файл з конфіденційними налаштуваннями (не зберігається у репозиторії)
